# mm-components

Custom elements (Web Components) du site maximemienne.fr, servis par jsDelivr et intégrés dans Wix via « Élément personnalisé > URL de serveur ».

Fichiers générés depuis le dépôt du site (sources dans `src/public/custom-elements/`, bundle esbuild avec Motion). Ne pas modifier à la main.

| Fichier | Balise |
|---|---|
| `dist/mm-carousel.js` | `mm-carousel` |
| `dist/mm-reveal-text.js` | `mm-reveal-text` |
| `dist/mm-cursor.js` | `mm-cursor` |
| `dist/mm-about.js` | `mm-about` |
| `dist/mm-projects.js` | `mm-projects` |
| `dist/mm-contact.js` | `mm-contact` |

URL : `https://cdn.jsdelivr.net/gh/maxdubox/mm-components@<version>/dist/<fichier>`
